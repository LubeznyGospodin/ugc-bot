# 2026-08-01 — Система прогрева аккаунтов для ассистента

## Запрос пользователя
Ресёрч по прогреву аккаунтов (IG/YT/VK/TikTok) + встроить в бота систему для ассистента
Арины (Днепр, tg id 1197101122): отдельные пуши с заданиями, отчёт, контроль.
На ней залогинены аккаунты Сингл и PapKids — 7 персон × 3 соцсети = 21 аккаунт (VK не в счёт).

## Файлы, которые смотрел

## Сделано
- Новый `bot/warmup.py`:
  - схемы прогрева по фазам для ig/tt/yt (`PLAN`), функция `tasks_for(platform, day)`;
  - состояние — один JSON в `AppState` (ключ `warmup_state`), без новой таблицы;
  - луп `run_warmup_loop`: 10:00 — задачи ассистенту с кнопками «Готово» по персонам,
    15:00 — запрос скрина одного случайного аккаунта (выборочный аудит),
    20:00 — напоминание ассистенту + отчёт админам (факт + дисциплина 7 дней);
  - хендлеры: `/wu`, `/wu_add`, `/wu_del`, `/wu_push`, колбэк `wu:d:<key>`,
    приём фото от ассистента → пересылка админам;
  - `demo()` — самопроверка фазовой логики (`python -m bot.warmup`).
- `bot/config.py`: `assistant_id` (env `ASSISTANT_ID`, дефолт 1197101122).
- `main.py`: роутер прогрева подключён ДО root (иначе generic-хендлеры регистрации
  перехватят `/wu*` и фото), запуск `run_warmup_loop`.
- `.env.example`: `ASSISTANT_ID`.

## Решения / компромиссы
- Состояние в `AppState` одним блобом, а не отдельной таблицей: 7 персон × 30 дней —
  килобайты, глобальная перезапись безопасна при одном процессе. Помечено `ponytail:`.
- Часовой пояс Днепра зафиксирован как UTC+3 (лето), без DST. Помечено `ponytail:`.
- Контроль v1 — самоотметка + выборочный аудит скрином. Автопроверка состояния
  аккаунтов через ScrapeCreators (дельта подписок, охваты первых роликов) НЕ сделана —
  см. «Следующие шаги».

## Правка после ревью
- Аудит просит НЕ скрин профиля, а историю действий с таймстемпами (`AUDIT_BY_WEEKDAY`):
  пн — IG лайки, вт — TikTok экранное время, ср — YouTube история просмотров,
  чт — IG подписки, пт — TikTok «Понравившиеся», сб — YouTube подписки, вс — выходной.
  Счётчики на профиле ничего не доказывают, история — доказывает.
- Фото от ассистента без активного аудита пробрасывается дальше (`SkipHandler`),
  иначе роутер прогрева глушил бы чужие хендлеры.
- Инструкция отправлена Арине (1197101122) и Игорю (357892821) через @ugc_radarbot.
- Состав: PapKids 5 каналов + Сингл 2 канала («Скажи песней», «Песня в подарок»).

## Правка 2 (после уточнений)
- Только «Сингл»: 2 персоны («Скажи песней», «Песня в подарок») × 3 соцсети = 6 аккаунтов.
  PapKids из работы ассистента убран.
- Публикация из задач убрана целиком — постит upload-post. В задачах осталась только
  человеческая активность + ответы на комментарии и 1–2 сторис в неделю с телефона.
- Скрин-аудит заменён на ВЫГРУЗКУ данных аккаунта раз в 3 дня (ротация ig→tt→yt):
  `EXPORTS` — точные инструкции по Instagram DYI / TikTok Download my data / Google Takeout.

  `parse_export` схема-агностично собирает все таймстемпы и группирует по имени файла
  → `_export_table` (события × 7 дней) → `_analyze` (Claude, `claude-opus-5`) → отчёт админам.
- `anthropic` добавлен в requirements, `ANTHROPIC_API_KEY` — в `settings`.
- `demo()` расширен: три реальные формы дат (unix-сек / TikTok-строка / Takeout ISO)
  + проверка, что id/bool/float не считаются датами.
