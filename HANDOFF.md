## 1. Что это и зачем
Telegram-бот **@ugc_radarbot** («UGC RADAR») для Packman Production. Регистрирует
UGC-креаторов, показывает запросы брендов, даёт откликаться, отслеживать статус
откликов (на рассмотрении / отказ / оффер), а админам — аналитику/рассылку/экспорт.
Бизнес-цель Игоря: чтобы работало быстро и с первого раза, и чтобы можно было
принимать реальные заявки брендов. Комьюнити-фичи: персональная лента брендов,
трек-рекорд/уровень креатора, пуш при смене статуса.

## 2. Архитектура и стек
- **Бот**: Python, aiogram 3 (polling), деплой на **Railway** (проект `spectacular-art`,
  сервис бота). Точка входа `main.py`.
- **БД (рантайм, быстрая)**: **Postgres** на Railway (недавно мигрировали с эфемерной
  SQLite). Бот читает из БД мгновенно. Подключение через `DATABASE_URL` (Railway
  Variables → `${{Postgres.DATABASE_URL}}`). Драйвер asyncpg. Код универсален:
  `bot/config._normalize_db_url` понимает и sqlite, и postgres.
- **Источник правды (данные)**: **Google-таблица**
  `https://docs.google.com/spreadsheets/d/1Hoqi-lLxyJtApNR6WGN59Rwz0u0hLPqFuDE-fQbzYyI`
  Вкладки: `Ответы на форму (1)` (креаторы), `Отклики`, `Бренды`.
- **Мост таблица↔бот**: **Google Apps Script** web-app (webhook, один POST-эндпоинт,
  роутинг по `action`). Скрипт-проект id `1GZBFC5V7icrhHFxVgtshnCxl9M9JfIZxtdpp0w-ZckGV75FaqQBbd2gI`.
  Текущая задеплоенная версия — **Версия 8** (URL/Deployment ID стабильны между версиями).
- **Синхронизация**: `bot/sync.py` — фоновый цикл каждые 120с тянет из таблицы в БД:
  бренды, креаторов, отклики. Плюс stale-while-revalidate на открытии экранов.

### Поток данных
Пользователь жмёт кнопку → бот читает из **БД** (быстро). Фоновый синк держит БД
свежей из таблицы. Запись (регистрация, отклик, правка анкеты) идёт в таблицу через
webhook (+ отклик сразу в БД, запись в таблицу в фоне). Пуш о статусе: onEdit-триггер
в Apps Script шлёт сообщение в Telegram напрямую (токен из Script Properties).

## 5. Деплой / откат / бэкапы
- **Смоук**: `bash check.sh` — обязательно перед деплоем.
- **Деплой бота**: `cd ~/Desktop/ugc_bot_v2 && railway up` (только с машины Игоря/CLI).
- **Деплой Apps Script**: редактор → Начать развёртывание → Управление развёртываниями →
  ✎ → Версия: «Новая версия» → Начать развёртывание. (В Claude Code лучше подключить
  **clasp**, чтобы пушить скрипт из терминала и не мучиться с редактором.)
- **Откат бота**: Railway → сервис → Deployments → Rollback/Redeploy на прошлый деплой.
- **Откат кода**: git — `git log --oneline`, `git restore .`, `git checkout <hash> -- .`.
- **Откат Apps Script**: Развёртывания → выбрать старую Версию (1–8).
- **Данные**: таблица — источник правды; Postgres пересобирается синком; у Railway
  есть Postgres Backups.
- Git: коммитить рабочее состояние перед каждой правкой. (Из песочницы Cowork запись
  в `.git` была заблокирована правами — в Claude Code это норм.)

## 7. Открытые задачи / известные баги
- **Автоскролл на /start**: анимация поиска редактирует ОДНО сообщение in-place
  (edit_message_text) → во время поиска чат не скроллится (это природа edit, не send).
  Пути «не найден»/«подтверди» тоже используют edit (нет скролла). ФИКС-идея: финальный
  результат /start слать через `render_screen` (новое сообщение → скролл) для всех веток.
- **Рейтинг/уровень креатора**: сейчас это трек-рекорд в «Моя анкета»
  («📊 Откликов N · Офферов M · Уровень: Новичок/Про/Топ»), считается АВТОМАТически из
  откликов (offers): 0 офф.=Новичок, ≥1 офф. или ≥3 откл.=Про, ≥3 офф.=Топ. Отдельного
  управляемого «рейтинга»/лидерборда нет — если нужен (админ ставит рейтинг вручную или
  публичный топ), это новая фича. Логика уровня — `bot/handlers/profile.py::_track_record_line`.
- **Пуш при смене статуса**: механизм готов (onEdit + токен из Script Properties). Ранее
  не приходил из-за незавершённой авторизации / токена — проверить, что `setupStatusPush`
  установил триггер и `BOT_TOKEN` в Script Properties валиден (getMe → ok:true).
- **Карточка вакансии** (хотел Игорь): фото бренда, описание, ссылка сайт/инста, кто
  нужен, условия — нужно добавить колонки в лист «Бренды» + переверстать карточку.
- **Стильная анимация**: Игорь хочет анимированный СТИКЕР (как у @bro_hit_bot). Нужен
  file_id стикера от Игоря → слать его на время загрузки, удалять по готовности.
- **Мусор в старых строках таблицы**: chat_id продублирован в V, дата в W, «да» в U —
  чтение не ломает (по заголовкам), можно подчистить.
- Триггеры: жёсткие фразы Игоря — «1 в 1», «в этот момент», «проверь сам», «не тормозить
  Bitrix», «не выкатывай старую версию», «сделай точно» — выполнять буквально.

## 8. Почему Claude Code лучше для этой задачи
- Нативный git (коммиты/откаты без блокировок песочницы), терминал, запуск `check.sh`.
- Прямое редактирование файлов и `railway up` из одной среды.
- Apps Script через **clasp** (CLI) — редактировать/пушить скрипт из терминала, без
  глючного веб-редактора (главный источник трения в Cowork).
- Меньше «невидимого процесса» — все правки как git-дифф.
