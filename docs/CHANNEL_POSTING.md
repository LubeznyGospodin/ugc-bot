# Постинг в канал @ugc_creatory — лог системных фиксов (не повторять!)

Каждую системную правку по каналу фиксируем здесь + в auto-memory `video-posting-invariants`.
Требование заказчика: перестать повторять одни и те же косяки.

## ТВЁРДЫЕ инварианты видео в канале
Любой путь (Telethon `channel_post.py`, бот `bot/handlers/placement.py`, будущие) обязан:

1. **Видео как ВИДЕО, не файл.** Работа, залитая креатором файлом (document-file_id), в
   `sendMediaGroup type:video` уходит `.MP4`-вложением. → скачать (Bot API ≤20МБ) и перезалить
   как video. >20МБ Bot API не тянет → пропустить (лучше меньше видео, чем файл).
2. **Обложка не чёрная.** Fade-in рилса → кадр 0 чёрный → автообложка чёрная. Задавать
   `thumbnail` явно: `ffmpeg -ss 1 -i in -frames:v 1 -vf scale=320:-2 -q:v 3`.
3. **Не квадрат.** Размеры брать `ffprobe` с ФАЙЛА (rotation-aware: ±90°→swap w/h), НЕ из
   атрибутов исходного сообщения (там 320×320/0). Слать `width/height/duration/supports_streaming`.

Реализация: `bot/utils/video.py` (`probe_dims`+`make_thumb`), `channel_post.py` (`_probe`+`_thumb`).
Нормализованный video-file_id кэшируется в `creator_works.file_id`. ffmpeg на Railway — `nixpacks.toml`.

## Хронология фиксов
- Чёрный первый кадр видео (Telethon-путь `channel_post.py`) → обложка ffmpeg `-ss 1`.
- Сплющивание в квадрат → размеры из `ffprobe` (не из атрибутов сообщения), rotation-aware.
- Видео уходят файлами (бот-постинг по document-file_id) → перезалив как video (`_video_ids`).
- ⚠️ РЕГРЕССИЯ: бот-перезалив без обложки/размеров вернул чёрный кадр + квадрат → добавлены
  `probe_dims`+`make_thumb` в бот-нормализацию (этот же инвариант, что и в Telethon-пути).
- ⚠️ РЕГРЕССИЯ 2: квадрат остался у видео, пришедших как VIDEO (не document) — бот пропускал их
  насквозь. Причина: Telegram у исходного video-file_id держит кривые (320×320) метаданные ДАЖЕ
  если файл портретный (ffprobe 720×1280). Фикс: `_video_ids` нормализует ВСЕ видео ≤20МБ (не
  только document), флаг `creator_works.normalized` чтоб не гонять повторно. ffmpeg на Railway —
  через Dockerfile (nixpacks aptPkgs игнорился, ловилось логом `ffmpeg=None` при старте).

## Протокол публикации
Размещаем в канал ТОЛЬКО согласованных заказчиком (кнопка «Разместить» в боте). Массово в
канал не лить. Промпт админу = альбом-превью (что уйдёт) + кнопки [✅ Разместить][❌ Нахер].
